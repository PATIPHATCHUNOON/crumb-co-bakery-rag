# Crumb & Co. — เว็บร้านเบเกอรี่พร้อมแชทบอท RAG

โปรเจ็กต์ร้านเบเกอรี่สมมติแบบ static site สำหรับ GitHub Pages สร้างจากแนวคิดของไฟล์ PIMChat ที่อาจารย์ให้มา มีหน้าสินค้า ตัวกรอง ตะกร้า และแชทบอทสำหรับลูกค้าที่ค้นจากเอกสาร `docs/*.txt` พร้อมแสดงไฟล์อ้างอิง เอกสารที่เว็บอ่านมีเฉพาะข้อมูลสินค้าและบริการที่ลูกค้าควรทราบ

อ่าน `AI_SETUP.md` สำหรับขั้นตอนเปิด AI ผ่านบัญชีของคุณ ข้อมูลภายในร้านสำหรับเจ้าของและการตอบอาจารย์จัดส่งเป็นไฟล์แยก ไม่อยู่ในโฟลเดอร์เว็บนี้

## ทดลองบนเครื่อง

เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน:

```powershell
py -m http.server 8000
```

เปิด `http://localhost:8000` ในเบราว์เซอร์ การเปิด `index.html` ตรงจาก `file://` อาจทำให้เบราว์เซอร์อ่านเอกสารด้วย `fetch()` ไม่ได้

หากไม่มี Python สามารถใช้ส่วนขยาย Live Server ของ VS Code หรือเว็บเซิร์ฟเวอร์ static อื่นได้

## สิ่งที่ทำงานแล้ว

- แสดงสินค้า 4 รายการ กรองประเภท เพิ่ม/ลดจำนวนในตะกร้า และคัดลอกสรุปรายการ
- แชทบอทอ่านเอกสารลูกค้า 13 ไฟล์ที่มีคู่คำถาม–คำตอบ 106 เรื่อง ตอบตรงจากเอกสารและแสดงแหล่งอ้างอิงโดยไม่ต้องใช้ API key
- กล่องแชตแจ้งชัดเจนว่าเป็นระบบอัตโนมัติหรือ AI ตามโหมดที่ใช้งาน และบอกวิธีติดต่อพนักงานที่เคาน์เตอร์
- เบอร์ `02-XXX-XXXX` ในส่วนติดต่อเป็นข้อมูลจำลองสำหรับการนำเสนอ ใช้โทรไม่ได้จริง
- `chat-search.js` ช่วยจับความหมายคำถามสั้น เช่น `เวลา`, `ราคา`, `เมนู`, `ส่วนผสม`, `ค่าส่ง`, `รับเอง` และชื่อขนม ก่อนค้นคู่คำถาม–คำตอบ
- คำถามที่ตรงกับคำถามในเอกสารตอบทันทีพร้อมอ้างอิง โดยไม่ต้องรอ AI; คำถามใหม่ยังค้นเวกเตอร์และให้ AI เรียบเรียง
- โมเดลตอบข้อความตั้งเป็น `nvidia/nemotron-3.5-lightning:free` เพื่อลดเวลารอ; โมเดลสร้างเวกเตอร์ยังเป็นรุ่นเดิม จึงไม่ต้องสร้าง `vectors.json` ใหม่เพราะการเปลี่ยนโมเดลตอบ
- กรณีตั้ง `WORKER_URL` แล้ว จะเรียก AI ผ่าน Cloudflare Worker เพื่อเรียบเรียงคำตอบจากเอกสาร
- สร้าง `vectors.json` จากเอกสารลูกค้า 55 ชิ้น และเปิดการค้นแบบเวกเตอร์แล้ว

ตะกร้ายังไม่ส่งคำสั่งซื้อจริงและไม่มีการรับชำระเงิน แชทใช้ AI ผ่าน Cloudflare Worker และ OpenRouter เพื่อเรียบเรียงคำตอบจากเอกสารร้าน

## ข้อมูลร้านที่บอทตอบได้

เอกสาร 13 ไฟล์ครอบคลุมเมนูและราคาขาย ส่วนผสมและสารก่อภูมิแพ้ วิธีใช้ตะกร้า เวลาเปิดและที่ตั้ง รายละเอียดสินค้าแต่ละชิ้น การเลือกเมนู การเก็บขนม และเงื่อนไขจัดส่ง หากถามข้อมูลภายในร้าน เช่น ต้นทุน กำไร หรือยอดขาย บอทจะไม่เปิดเผยและชวนถามเรื่องสินค้าและบริการแทน

## แก้เป็นร้านที่เปิดขายจริง

1. แก้ชื่อร้าน ข้อความ และส่วนต่าง ๆ ใน `index.html`
2. แก้รายการสินค้าและราคาใน `shop.js` **พร้อมแก้ราคาใน `docs/01-menu.txt` ให้ตรงกัน**
3. แก้เอกสารทุกไฟล์ใน `docs/` ให้เป็นข้อมูลที่ตรวจสอบจากการผลิตจริง โดยเฉพาะน้ำหนัก ส่วนผสม สารก่อภูมิแพ้ การรับคำสั่งซื้อ และช่องทางติดต่อ
4. แก้รายการ `FILES` ใน `config.js` เมื่อเพิ่มหรือลบไฟล์เอกสาร
5. ตรวจเวลาเปิด ที่ตั้ง ช่องทางรับรายการ และค่าส่งในทุกไฟล์ให้ตรงกับธุรกิจที่จะใช้จริง

อย่านำสูตร น้ำหนัก หรือข้อมูลสารก่อภูมิแพ้ของร้านสมมตินี้ไปใช้เป็นฉลากสินค้าจริงโดยไม่ตรวจสอบ

## เปิด AI ผ่าน Worker

1. สร้าง OpenRouter API key ในบัญชีของคุณ **อย่าใส่ key ใน `config.js`, GitHub หรือแชท**
2. Deploy Cloudflare Worker ด้วย `worker.js` และ `wrangler.jsonc` ซึ่งเตรียม `ALLOWED` สำหรับ Sites และ GitHub Pages ของ PATIPHATCHUNOON ไว้แล้ว
3. เพิ่ม Secret ชื่อ `OPENROUTER_KEY` ในหน้า Cloudflare Worker
4. เปิด URL ของ Worker ต้องได้ `{"status":"ok","hasKey":true}`
5. ใส่ URL ของ Worker ใน `config.js` ที่ `WORKER_URL` โดยไม่ใส่ `/` ท้ายสุด
6. ตรวจว่า `MODEL` และ `EMBED_MODEL` ยังเป็นชื่อรุ่นที่ใช้งานได้ใน OpenRouter
7. ตอนนี้ตั้ง `SEARCH_MODE: 'vector'` และมี `vectors.json` แล้ว หากเปลี่ยนเอกสารหรือโมเดลให้สร้างไฟล์ใหม่

การมี Worker ช่วยไม่ให้ key อยู่ในโค้ดหน้าเว็บ ผู้พัฒนายังคงต้องจัดการสิทธิ์และโควตาของบัญชีด้วยตนเอง

## เปิด Vector Search

1. เมื่อ Worker ทำงานแล้ว เปิด `/build-vectors.html` บนเว็บที่อนุญาตใน `ALLOWED`
2. กดสร้างและดาวน์โหลด `vectors.json` วางไว้ชั้นเดียวกับ `index.html`
3. เปลี่ยน `SEARCH_MODE` ใน `config.js` เป็น `'vector'`
4. หากแก้เอกสาร, `EMBED_MODEL`, `CHUNK_SIZE` หรือ `OVERLAP` ต้องสร้าง `vectors.json` ใหม่

หากไม่มีไฟล์เวกเตอร์ ระบบจะใช้การค้นข้อความสำรองและแสดงสถานะให้เห็น

## ส่งงานตามคู่มืออาจารย์

อัปไฟล์ในโฟลเดอร์นี้ขึ้น GitHub repository แบบ Public แล้วเปิด GitHub Pages จาก branch `main` โฟลเดอร์ `/ (root)` ก่อนนำเสนอควรตรวจว่าเว็บเปิดจากเครื่องอื่นได้, ลิงก์ repository ใช้ได้ และมี `vectors.json` เมื่ออาจารย์กำหนดให้ใช้โหมดเวกเตอร์

## คำถามทดสอบ

- `ครัวซองต์อัลมอนด์ราคาเท่าไร` → 95 บาท, อ้าง `06-croissant.txt`
- `ซาวโดว์มีไข่ไหม` → สูตรที่กำหนดไม่ใส่ไข่, อ้าง `08-sourdough.txt`
- `กำไรเท่าไร` → แจ้งว่าเป็นข้อมูลภายในร้าน ไม่เปิดเผยตัวเลข
- `สั่งซื้อผ่านเว็บได้ไหม` → ตะกร้าสรุปรายการ แล้วนำไปยืนยันกับพนักงานที่เคาน์เตอร์ อ้าง `03-orders.txt`
- `ค่าส่งเท่าไร` → ไม่เกิน 5 กม. 40 บาท (ฟรีเมื่อครบ 500 บาท), เกิน 5–10 กม. 70 บาท อ้าง `11-delivery.txt`
- คำถามนอกเอกสาร → ควรบอกว่าไม่พบข้อมูล ไม่เดาคำตอบ
